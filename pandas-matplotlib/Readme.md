# **Pandas Practice** - World Happiness Report 2021

Using data from [world-happiness-report-2021.csv](resources/world-happiness-report-2021.csv) solving 30 questions ranging easy, medium and hard.

## EASY (1–10) — Exploration & Basics

1. Load the dataset into a DataFrame.
2. Display the first 10 rows of the dataset.
3. Find the number of rows and columns.
4. List all column names.
5. Check the data type of each column.
6. Identify columns that contain missing values.
7. Count the total number of missing values in the dataset.
8. Display summary statistics for all numerical columns.
9. Find the average happiness score across all countries.
10. Find the country with the highest happiness score.

## MEDIUM (11–20) — Filtering, Sorting, Aggregation

11. Find the country with the lowest happiness score.
12. List the top 10 happiest countries.
13. List the bottom 10 least happy countries.
14. Find the average happiness score by region.
15. Find which region has the highest average happiness score.
16. Find how many countries belong to each region.
17. Find the range (max − min) of happiness scores for each region.
18. Find countries whose happiness score is above the global average.
19. Sort countries by GDP per capita and list the top 10.
20. Find the average life expectancy for countries with happiness score above 6.

## HARD (21–30) — Analysis & Derived Insights

21. Rank all countries by happiness score.
22. Find India’s rank in happiness score.
23. Find the top 5 happiest countries in Asia.
24. Create a new column that categorizes countries into:
    * Very Happy
    * Happy
    * Neutral
    * Unhappy
      (based on happiness score ranges you define)
25. Find the average GDP per capita for each happiness category.
26. Find which factor (GDP, social support, life expectancy, freedom, generosity, corruption perception) has the strongest relationship with happiness score.
27. Find regions where the happiness score variance is highest.
28. Identify countries that rank high in happiness despite low GDP per capita.
29. Compare happiness score distributions between Europe and Asia.
30. Create a summary table showing:
    * Region
    * Average happiness score
    * Highest score
    * Lowest score
    * Number of countries
